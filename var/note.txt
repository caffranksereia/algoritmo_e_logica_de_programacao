variavel e uma porcao de memoria utilizado
para armazenar dados durante execucao do 
programa

sintaxe
<name> : <tipo>

exem:
idade: inteiro
altura: real
logradouro: caractere

Uma variavel possui:
Nome: (ou identificador)
tipo
valor
endereco

| Tipo        | Descrição                  | Valor inicial | Exemplos                  |
| ----------- | -------------------------- | ------------: | ------------------------- |
| `inteiro`   | Números inteiros           |           `0` | `-10`, `0`, `25`, `100`   |
| `real`      | Números com casas decimais |           `0` | `3.14`, `10.5`, `-2.7`    |
| `caractere` | Texto ou caracteres        |          `""` | `"Olá"`, `"Fabio"`, `"A"` |
| `logico`    | Valor lógico               |       `FALSO` | `VERDADEIRO` ou `FALSO`   |

exemplo praticos:

Nome	Tipo	Valor
idade	inteiro	32
altura	real	1.75
nome	caractere	"Fabio"
estudando	lógico	Verdadeiro
