# Comando `leia`

No **VisualG**, o comando `leia` é utilizado para receber um valor digitado pelo usuário e armazená-lo em uma variável.

## Sintaxe

```text
leia(variavel)
```

Exemplo:

```text
leia(x)
```

Nesse caso, o valor digitado pelo usuário será armazenado na variável `x`.

---
